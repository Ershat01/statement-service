Распаковка гит, запуск микросервиса, подкючение к базе, localhost = я сам, значит у каждого сервиса свой хост, была ошибка где через микросервисы не было доступа к базе, поменяли явно указав postgres (docker-compose.yml)
Docker Compose поднимает общую сеть и заводит внутренний DNS, где имя сервиса из compose-файла становится хостнеймом
${DB_HOST:localhost} это spring, говорит бери из db_host если нет то из localhost
Flyway создает таблицы в базе, пишешь sql файлы с номерами (v1__init.sql), на старте приложения выполняет их по порядку, дважды одно и то же не выполняет, запоминает в служебной таблице что уже отработано
в Spring Boot 4 отсутствие стартера ломает вещи молча, без ошибки на старте
